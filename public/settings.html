大语言模型（小和的大脑）

配置后，小和可以自由问答、承接追问，并理解自然语言找书。普通对话会发送本次问题与最近 6 轮对话，找书理解会发送转写文本与真实馆藏目录；本机识别的音频不发送给大模型。 不配置时仍能按书名找已入库的书、翻页和归还。模型运行在服务商服务器，本机无需大模型显卡。DeepSeek 默认关闭思考模式（普通问答、找书与连接测试均关闭），回答完整显示在小和的像素气泡中。

采用 Chat Completions 兼容协议；地址填写到 API 根路径（如 https://api.deepseek.com 或供应商要求的 /v1），程序自动追加 /chat/completions。切换服务时请填写对应密钥与真实模型 ID。Anthropic、Gemini 等原生协议需使用兼容网关。保存后下一次提问生效，切换模型会重置对话上下文。

联网搜索与网页阅读

        
小和可按问题需要搜索网页、读取网页后回答，来源显示在像素气泡中。普通闲聊不主动联网。DeepSeek Search / Fetch 各为每千次成功请求 5 元，模型费用另计；每轮最多 3 次联网请求。

        
        
        

        
        
        
对话使用官方 DeepSeek 时自动复用已有密钥，无需重填。改用其它对话服务后，可在此单独填写 DeepSeek 密钥，搜索仍由 DeepSeek 提供。密钥只发送给官方接口。

        

        

      


      

        
语音快捷键

        

          轻按一下左边的 Alt 键，等于叫一声「小和」；轻按一下再马上按住 Alt，就可以直接说话，松开时把这段话交给小和，不用先叫名字。
          按住说话时麦克风只在按住期间打开，即使关闭了语音感知也能用。Alt 和别的键一起按（例如 Alt+Tab）不会触发；在输入框里打字时也不会。
        

        
        
        

      


      

        
小和记得的事

        

          小和会记住三类事：你明确说「记住……」的内容、你打开过的书和读到哪一章、每段对话结束后的一句话摘要。
          写摘要的同一次调用里，小和还可以记下自己的推测（例如「最近在看历史书」）和对你的整体印象；这些都标明是推测，
          不会改动你亲口交代的事，也可以单独关掉。
          它们只保存在这台电脑上（—）。和小和聊天时，其中最相关的几条（不超过 520 字）
          会随问题一起发给你配置的大模型服务，好让它接着上次聊；可以逐条删除、全部清空，或完全关闭。
