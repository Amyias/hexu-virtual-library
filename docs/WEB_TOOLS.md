# 小和的联网工具

语音转写与文字对话共用 `assistant.processText`。普通问答进入 `/chat` 后，模型可以返回 `web_search` / `web_fetch` 函数调用；服务端执行工具，把结果作为 `tool` 消息交回模型，得到最终回答。书架定位、翻页、归还仍走现有本地操作。

官方接口：

| 功能 | 固定服务地址 | 输入 |
| --- | --- | --- |
| 搜索 | `POST https://api.deepseek.com/v1/tools/search` | `query`，1～128 字；程序固定取 4 条摘要 |
| 抓取 | `POST https://api.deepseek.com/v1/tools/fetch` | 公开网页 `url`；返回 Markdown 正文 |

## 配置

打开「和 · 对话 → 模型设置 → 联网搜索与网页阅读」。按需开启联网后，官方 DeepSeek 对话默认复用已有密钥。对话改用其它服务时，需要在独立搜索密钥栏配置 DeepSeek 密钥。空白保存不会覆盖已有密钥，清除按钮只清除独立搜索密钥。

部署也可用环境变量，环境变量优先于用户设置文件：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `HEXU_WEB_ENABLED` | `1` | `0` 关闭联网，`1` 允许模型按需使用 |
| `HEXU_WEB_API_KEY` | 空 | 可选的独立 DeepSeek 搜索密钥。仅在对话地址为官方 `api.deepseek.com` 时允许自动复用对话密钥 |
| `HEXU_LLM_CHAT_TIMEOUT` | `60` | 模型和工具共用本轮总时限，网页单次最多 12 秒 |

不新增搜索地址设置。搜索密钥只发送到固定的 DeepSeek 官方接口；对话密钥不会因为切换模型被发送给另一个搜索供应商。模型设置的连接测试不调用联网工具。

## 行为与限制

- 普通知识、写作、闲聊直接回答；最新信息、事实核实、用户明确联网请求可以搜索，指定网址可以抓取。是否使用工具由对话模型判断；其它模型需支持 Chat Completions 函数调用。
- 每轮最多 3 次网页请求、2 轮工具调用，达到限制后强制结束工具调用并生成回答；不自动重试计费请求。
- 工具参数严格验证，拒绝本机、内网 IP、带账号密码和非 HTTP/HTTPS 链接。服务端只连接 DeepSeek，不直接访问目标网页；目标页面是否可读取还受 DeepSeek 与目标站点策略约束。
- 搜索摘要和正文均限制长度，响应体最多 1 MB。网页资料是第三方不可信内容，不是应用指令；模型无下载、执行文件、写入书库的工具。
- 未启用、失败、无结果均不得声称已经核实。错误提示不回传供应商原始错误体，不回显密钥。
- 仅成功工具结果产生来源条目，最多 8 条、按网址去重。模型正文按纯文本显示，来源单独用安全 DOM 创建链接；气泡和对话记录均支持点击来源。
- 六轮会话历史只保留用户问题与最终回答，不持久保存网页全文。取消等待会丢弃迟到的前端回复，已发出的后端/API 请求可能继续执行并计费，后端仍受次数及总超时限制。
- 搜索会把提炼后的搜索词发送给 DeepSeek；抓取会把目标 URL 发送给 DeepSeek，网页摘要/正文会发给当前对话模型。普通问答原有的数据边界不变。

## 验证

`npm test` 包含搜索→抓取→模型回答、官方与独立密钥、关闭开关、空结果、错误、URL 校验、限次、超时和设置接口的测试；测试不使用真实凭据。`npm run test:ui` 验证原有阅读闭环，联网专用浏览器验证需额外检查来源、语音转写分发和逐字气泡。

真实接口验收应通过程序已保存的配置进行，不在脚本中读取、复制或打印使用者密钥。不能把模拟 HTTP 测试当成官方接口已连通的证明。

参考：[网页搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search/)、[工具调用](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)。Search / Fetch 各按成功且有结果的请求计费，当前各为 5 元/千次，模型 token 另计。
