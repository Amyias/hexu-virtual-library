# 本地正文书库与小说阅读

书架不预装样书。正文通过本机服务下载或导入，保存到独立书库；网页打开时读取真实书目，绑定空槽位并显示书本。未入库的位置保持空置。模型模板与芯片编号仍可复用。

新书从第 2 架 A 面靠前台的一端开始上架，同一列由上层往下放，读者从前台和走道一眼就能看到；已入库的书保持原有编号与位置，不会因此移动。

## 如何使用

1. 启动最新版源码服务 `npm start`，或使用重新打包后的本机程序。源码模式的书库服务需要 Python 3.10+；先用该解释器运行 `python -m pip install -r tools/requirements-sources.txt` 安装解析依赖。SQLite 使用标准库，不需另装数据库。若 Python 不在 PATH，可设置 `HEXU_PYTHON` 指向解释器，再启动服务。
2. 点击一次「启动语音感知」，允许麦克风。说「小和」，小和仅回答「有什么需求吗？」；接着说「帮我找狂人日记」。也可以直接说「小和，帮我找狂人日记」。文字搜索框走相同的找书逻辑。
3. 已有本地正文时直接取书，不访问在线书源。未入库的书名会进入在线正文检索；精确结果唯一时自动下载，多个候选时在面板选择「下载并上架」。下载进度会显示当前章节，支持取消。
4. 手动点击「下载并上架」后，对应空槽位会新增一本实体书，视角自动靠近并框出它，书保留在架上。书库列表会显示架号、面、层、顺序与芯片编号；「定位书架」只查看位置，「从书架取阅」才让小和取出书本。语音明确找书、唯一结果自动下载时，仍会直接取阅。向左拖动封面，或点击「翻开书页」，进入正文阅读。也可点击「阅读正文」。
5. 用上一页、下一页、左右方向键或水平滑动翻页；目录可直接跳章，A−/A＋调整字号。阅读位置按章节与字符偏移保存，重新打开会恢复。
6. 点击「返回 3D 书本」查看芯片，随后「放回书架」。小和回到前台待命。语音也支持「小和，下一页」「小和，上一页」「小和，读正文」「小和，看芯片」「小和，放回书架」。

书架只展示已下载或导入的真实书籍，重启后从书库恢复相同位置。全景里单本书脊很细，可以在正文书库点击「定位书架」查看；点击右下角「重置视角」回到前台全景。

## 书源连接失败时

搜索会保留已成功书源的结果，并在失败项中显示书源名称及原因：DNS 解析失败、连接超时、连接被拒绝／中断、网络不可达、HTTPS 证书校验或握手失败；未能分类的错误仍显示连接失败。错误消息不包含底层原始地址或代理细节。某些书源失败时，不会将其解释成站点没有这本书。

点击失败项的「重试此书源」，只重新搜索该书源，保留同次查询的其他成功结果；重复失败会更新原因，恢复后会合并结果并移除对应错误。重试仍使用原查询书名，不会把尚未提交的输入框内容带入重试。程序不切换 VPN、不改系统 DNS／代理，也不跳过 HTTPS 证书校验。代理关闭后站点是否可连接，仍取决于实际网络；本功能用于给出准确提示并便于重试，不保证外站在所有网络下都可达。

Windows 上的内置书源还有自动兼容路径：Python 请求遇到连接异常后，通过 `%SystemRoot%/System32/curl.exe` 使用系统 Schannel HTTPS 与 IPv4 再试一次。备用请求总预算 12 秒、最多 4 次跳转，响应正文最多 4 MiB、响应头最多 64 KiB，仍限制为同一内置 HTTPS 站点。证书校验失败和 HTTP 拒绝不会触发该路径。curl 配置文件不加载，原始错误不回显，未安装系统 curl 时保留原错误；自定义书源和大模型接口不使用此备用通道。它用于兼容系统网络／TLS 差异，不切换 VPN、不修改 DNS、不使用固定 IP，也不保证站点在所有线路都可达。

## 存储与备份

Windows 默认位置为 `%APPDATA%\hexu-library\books`；其他系统默认 `~/.local/share/hexu-library/books`。界面的「正文书库 → 书库位置」显示实际路径。可用环境变量 `HEXU_BOOK_LIBRARY_DIR` 指定其他目录。

目录内包含：

| 文件 | 内容 |
| --- | --- |
| `library.sqlite` | 书目、完整章节、来源、书源规则与阅读进度 |
| `<书库ID>.txt` | UTF-8 全文副本，便于直接打开和备份 |

书库 ID 由来源与该来源的书籍标识生成，重复下载不会重复上架；书架槽位写入数据库，重启后位置稳定。网页将持久化槽位映射到物理位置，保留 HX 芯片编号与坐标。新增书目优先安排到文学书架，然后使用其他书架。移除样书后，通过清单中的数字兼容映射保持所有旧书库的位置不变；过去跳过的 12 个位置追加到末尾。

关闭程序后复制整个书库目录即可备份。程序更新与 Git 源码提交不包含用户书库；搬到另一台电脑时另行复制它。阅读已下载的正文不需要外网，但本机 HTTP 服务仍须运行。浏览器的语音识别是否能离线使用取决于所选识别通道。

## 书源与文件导入

默认检索 [无忧书城](https://www.wyshu.com/) 和 [天涯书库](https://tianyashuku.net/)，[书包网（简体）](https://cn.shubaoc.com/) 保留为下拉框单独可选源。无忧书城的站内搜索需要浏览器安全验证，本程序不提交该表单，而是读取公开 `sitemap/bookname_1.xml`，用书名拼音及有界多音字变体定位最多 12 个目录，再核对真实书名和作者，最多返回 8 个候选；索引在进程内缓存 24 小时，最多 20000 项。目录索引检索不等于完整高级搜索，特殊标题可能需要完整书名或拼音，未命中会明确提示限制。目录和正文按普通公开页面读取，不运行网页脚本。天涯书库使用站内 POST 表单搜索，书包网使用 `/search/<书名>/` 搜索；候选展示来源，确认下载后依次读取完整目录及正文，保存书名、作者和来源链接。书包网目录每页 100 章，适配器会自动翻到最后一页；正文只提取章节区域，排除推荐、导航及脚本。所有内置站点共用取消、去重、进度与完整入库流程，每个站点的请求至少间隔 350 毫秒。

历史维基文库下载的书籍、来源记录、书架编号和阅读进度继续保留；本地精确命中时不发起网络请求。内置源走代码中固定的 HTTPS 域名并保留证书校验，支持本机系统 DNS／网络代理；导入的自定义源仍逐次检查公网地址，不能通过 JSON 放宽限制。

「正文书库 → 书源管理与导入」提供 [源仓库](https://www.yckceo.com/yuedu/shuyuan/index.html) 入口。可以下载 JSON 文件后导入，也可以直接**粘贴书源网址**（源仓库直链、GitHub raw、Gist 都可以）由程序拉取；面板分别列出成功和拒绝的书源及原因。

书源规则按阅读 App（Legado）的语法执行：

| 规则 | 支持的写法 |
| --- | --- |
| 链式选择器 | `class.名称.序号@tag.标签.序号@属性`，支持 `.0`、`.-1`、`!0` 排除、`[0:2]` 切片、`children[n]`、`text.文字` 按文字取节点 |
| 标准 CSS | `#id .cls:not([href='#'])`、`a.btn,.page>span`，尾部 `span.0` 这类 Legado 索引会先剥离再套用 |
| XPath / JSONPath | `@XPath:`、`//` 前缀；`@Json:`、`$` 前缀，以及 `data[0].name` 形式的取值 |
| 属性 | `@text`、`ownText`、`textNodes`、`html`、`all`、`href`、`src`、`title`、`content` 和任意属性名 |
| 拼接与备选 | `&&` 合并、`||` 依次尝试、`##正则##替换`、`{{key}}`/`{{page}}`/`{{$.字段}}`、`{{@@规则}}` 嵌套规则 |
| 整条正则 | 规则本身就是正则时按正则抽取，配合 `$1`…`$n` 取分组（起点这类目录用得到） |
| JS | `@js:`、`<js>…</js>`、`jsLib`，可用 `result`、`baseUrl`、`key`、`page`、`book`、`source` |

`java.*` 宿主接口做成了**有界实现**（`tools/legado_host.py`）：`base64Decode/Encode`、`hexDecodeToString`、`md5Encode/md5Encode16`、`timeFormat`、`encodeURI`、`java.put/get`（每源作用域的变量表）、`java.getString`，以及`java.ajax`——只能访问该书源自己的域名，GET/POST，单次响应 4 MiB，单条规则最多 4 次，仍然走公网地址检查与正常 TLS 校验。`longToast`、`startBrowserAwait`、`setContent` 这类界面接口是空实现；`getVerificationCode`（人工验证码）与 `Packages.*`（安卓类/设备注册）明确报错，这类源在导入时就会被拒绝并说明原因。

JS 的执行边界：纯 JS 规则仍限制 0.5 秒、32 MiB，没有本机文件、环境变量、进程与任意网络接口。带 `java.*` 的规则因为 quickjs 的限制不能同时设 JS 时间限制，改由每次宿主调用前的墙钟预算（默认 25 秒）与 4 次请求上限收口。

搜索 URL 支持 `{{key}}`、`{query}`、`{{page}}`（第一页）及 `{{JS表达式}}`；支持 `URL,{"method":"POST","body":"...","headers":{...}}` 请求选项。请求头仅允许 User-Agent、Accept、Accept-Language、Content-Type、Referer；正文为字符串，编码可为 UTF-8/GBK/GB18030。请求及跳转仍需符合该源同域与公网地址限制。

导入成功后默认启用，源文件标明 `enabled:false` 时保持停用；可在“书源管理与导入”的书源列表勾选开关，状态保存在本机。缺少搜索配置但具有书籍信息、目录与正文规则的源可以导入，标记“不提供搜索”，不会参加按书名搜索。在线书籍通过书名搜索后下载；本地书籍通过 TXT / EPUB 文件导入。`ruleBookInfo.tocUrl` 可指向独立目录，`nextTocUrl` 与 `nextContentUrl` 分别用于目录和正文分页，循环或中途失败不保存半本书。导入时只做离线规则验证；公网 DNS 检查在真正访问站点时进行。

以下为格式示例，需要改成实际站点的地址与选择器，不是可直接下载的书源：

```json
{
  "name": "My free-text source",
  "base_url": "https://example.com",
  "search_url": "/search?q={{key}}",
  "search": {
    "items": ".book-result",
    "title": "a.title@text",
    "url": "a.title@href",
    "author": ".author@text"
  },
  "toc": {
    "items": ".chapter-list a",
    "title": "@text",
    "url": "@href"
  },
  "content": {"body": "#chapter-content@text"},
  "license": "Publicly available free text; see source page"
}
```

仍不支持：Android 设备接口（`Packages.*`、设备号、APP 注册）、WebView 登录与人工验证码、跨域章节、图像/PDF 转文字，也不保证 Legado 的每一种选择器组合都能跑通。依赖这些能力的源会明确显示原因并拒绝启用；导入时不会运行 JS，也不会绕过站点访问控制。番茄小说这类正文依赖设备注册与加密的 APP 源无法在本机复现，请换网页源。

自定义书源仅访问其同域公开 HTTP(S) 地址；本机、内网和保留地址被拒绝。代理返回保留地址的 DNS 环境也可能阻止站点访问。书源启用表示配置已保存、规则已验证，不保证外站可连接或每本书都提供可下载正文。

「导入 TXT / EPUB」支持 UTF-8、带 BOM 的 UTF-16 与 GB18030 TXT，以及无加密的 EPUB。EPUB 按 spine 顺序读取，并将 HTML 转为纯文本，脚本不会进入页面。导入的是本机实际文件内容，不会发送给大语言模型。EPUB 自带的 ISBN（校验位核对过）、分类、简介、出版社与出版日期一并保存，简介用作书目摘要。带 ISBN 的书入库后会在后台查一次 [Open Library](https://openlibrary.org/dev/docs/api/books)（免费、无需密钥），只补文件里没有的分类、出版社、日期与页数，不覆盖文件自带的内容；查询只发送 ISBN，查不到或无法联网时什么都不改。设环境变量 `HEXU_METADATA_LOOKUP=0` 可关闭查询。

当前限制：单次导入文件 8 MiB，EPUB 解压后总量 32 MiB；在线单页响应 4 MiB，内置小说站与自定义书源一次最多 2000 章（历史维基文库适配器仍为 500 章）、目录最多 50 页、每章正文最多 20 页，整书最多 1000 万字符；最多两个同时下载任务。
取消会在当前网络请求结束后生效；失败或取消的任务不会作为完整书籍入库，重试从头下载。

## 多书源聚合检索

这一层相当于阅读 App 的「换源搜索」，代码在 `tools/aggregate_search.py`：

1. **全部源参与**：`默认搜索` 并发检索所有启用且支持搜索的书源（上限 40 个，12 路并发），不再只取前五个。
2. **独立超时**：每个源 12 秒独立超时，慢源不会拖住整次检索，其余源的结果照常返回；失败项仍可按源重试。
3. **同书合并**：书名与作者归一化后相同的结果合并成一条，附带每个源的下载入口。命中源越多分越高，排序依次看：书名完全一致、书名包含、多源命中、作者是否已知、书源健康度、源响应速度。
4. **健康度**：每个源的成功次数、失败次数、连续失败、最近延迟与最近错误都写进 `library.sqlite` 的 `source_health` 表。连续失败的源排序会被压低，成功一次立刻恢复；书源列表里直接显示「可用 N 次 · 320 ms」或「上次失败：HTTP 403」。
5. **书源体检**：`体检全部书源` 用当前搜索框里的书名（默认《三体》）逐个实跑一次，报告可用性、结果数与耗时，比「导入成功」更能说明这个源到底能不能用。
6. **失败换源下载**：下载任务按「主源 → 备用源 1 → 备用源 2」的顺序尝试，任一成功即入库，并把实际使用的源写进任务结果与书目元数据。
7. **自动停用**：某个自定义源连续失败到阈值（默认 5 次，可设 0 关闭）就自动停用并记下原因，避免每次都等它超时；在书源列表里勾选它即恢复，同时清零连败计数。内置源不在停用范围内；「书源不能访问本机/内网」「解析依赖未安装」这类整批中招的错误不计入连败（否则关掉 fake-IP 会把所有源一次停光）。
8. **书源订阅**：填一个订阅 JSON 地址即可，添加时立刻同步一次，之后每 12 小时自动拉取（进程启动 25 秒后开始检查，每 30 分钟看一次有没有到期）。订阅只管理它自己带进来的源：新增/更新这些源，源从订阅里消失时删除对应书源；**手动导入的源与用户手动的启用状态不会被订阅覆盖**。同步失败保留原有书源，只把失败原因写进订阅记录。

实测（`XIU2/Yuedu` 公开书源包，22 个热门源）：本版之前导入 0 个，本版导入 18 个；拒绝的 4 个里，1 个是 APP 专属源（番茄小说 2，需要安卓设备注册），3 个是源自身 `<js>` 里的正则没闭合（阅读 App 同样会报错）。用《三体》实跑，全部源并发 3.5 秒返回结果，命中的第一个就是《三体》/刘慈欣。其余 10 个源在当前网络下分别返回 403／502／503、连接中断或域名解析失败——这是站点侧与线路问题，健康度里会记下原因，不再表现为「导入成功但搜不到」。

## 模块与接口

```text
ASR / 文字输入
       ↓
src/app/assistant.js → 本地书目匹配 → 3D 取书与封面开合
       ↓ 未入库                     ↓
src/reader/library.js       src/reader/novel.js
       ↓ 搜索 / 下载 / 导入          ↓ 章节 / 分页 / 进度
                  /library/*
                       ↓
              tools/book_library.py
                  ↙             ↘
       tools/book_sources.py    SQLite + UTF-8 TXT
          ↙          ↘
 天涯 / 书包网     CSS / XPath / JSONPath / JS 书源
```

聚合检索在 `tools/aggregate_search.py`，规则引擎在 `tools/source_rules.py`，Legado 宿主接口在 `tools/legado_host.py`。

`npm start` 的 Node 服务按需启动 `tools/library-service.py` 子进程并代理 `/library/*`；Python 本机程序与服务器则直接复用 `book_library`，两条运行路径使用相同的数据库与下载逻辑。正文显示使用 `textContent`，不会把远端 HTML 当作可执行页面。

| 接口 | 用途 |
| --- | --- |
| `GET /library/ready` | 探测书库服务与实际存储路径 |
| `GET /library/books` | 已入库目录 |
| `GET /library/books/<id>` | 全部章节与保存的阅读位置 |
| `GET /library/search?q=...&source=all` | 本地优先、在线候选、同书合并分组与分来源错误 |
| `POST /library/search/jobs` | 建立增量检索任务（`{q, source}`），边搜边出 |
| `GET /library/search/jobs/<id>` | 任务进度、已到结果、分组与错误 |
| `POST /library/search/jobs/<id>` | 取消该检索任务 |
| `GET /library/sources` | 可用书源 |
| `POST /library/download` | 根据搜索候选建立异步任务 |
| `GET /library/jobs/<id>` | 下载状态和进度 |
| `POST /library/jobs/<id>` | 请求取消任务 |
| `POST /library/import` | 导入文件名与 Base64 文件内容 |
| `POST /library/sources` | 导入书源 JSON 对象或数组，返回能力与拒绝原因 |
| `POST /library/sources/import-url` | 从公开 URL 拉取并导入书源 `{ "url": ... }` |
| `POST /library/sources/<id>/probe` | 单个书源真实体检 `{ "q": "三体" }` |
| `GET /library/subscriptions` | 订阅列表（上次同步、导入/移除数、状态） |
| `POST /library/subscriptions` | 添加订阅并立刻同步 `{ "url": ..., "name": ... }` |
| `POST /library/subscriptions/<id>` | `{ "sync": true }` 立即同步、`{ "enabled": false }` 停用、`{ "delete": true }` 删除并移除它带来的源 |
| `POST /library/settings` | `allow_fake_ip` 或 `auto_disable_after`（0～99，0 关闭） |
| `POST /library/sources/<id>` | 设置 `{ "enabled": true/false }` |
| `POST /library/progress/<id>` | 保存 `chapter` 和 `offset` |

分页在当前窗口内测量真实文字高度，不使用固定字符数截断或简介占位。翻页的下一页起点等于上一页结束偏移，调整字号与窗口尺寸后重新排版；字符偏移让进度不依赖页码变化。
