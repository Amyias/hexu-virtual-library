# 本地正文书库与小说阅读

书架不预装样书。正文通过本机服务下载或导入，保存到独立书库；网页打开时读取真实书目，绑定空槽位并显示书本。未入库的位置保持空置。模型模板与芯片编号仍可复用。

## 如何使用

1. 启动最新版源码服务 `npm start`，或使用重新打包后的本机程序。源码模式的书库服务需要 Python 3.10+；先用该解释器运行 `python -m pip install -r tools/requirements-sources.txt` 安装解析依赖。SQLite 使用标准库，不需另装数据库。若 Python 不在 PATH，可设置 `HEXU_PYTHON` 指向解释器，再启动服务。
2. 点击一次「启动语音感知」，允许麦克风。说「小和」，小和仅回答「有什么需求吗？」；接着说「帮我找狂人日记」。也可以直接说「小和，帮我找狂人日记」。文字搜索框走相同的找书逻辑。
3. 已有本地正文时直接取书，不访问在线书源。未入库的书名会进入在线正文检索；精确结果唯一时自动下载，多个候选时在面板选择「下载并上架」。下载进度会显示当前章节，支持取消。
4. 正文完整保存后，小和飞到绑定的书架位置并取出书本。向左拖动封面，或点击「翻开书页」，进入正文阅读。也可点击「阅读正文」。
5. 用上一页、下一页、左右方向键或水平滑动翻页；目录可直接跳章，A−/A＋调整字号。阅读位置按章节与字符偏移保存，重新打开会恢复。
6. 点击「返回 3D 书本」查看芯片，随后「放回书架」。小和回到前台待命。语音也支持「小和，下一页」「小和，上一页」「小和，读正文」「小和，看芯片」「小和，放回书架」。

原有 12 本演示馆藏仍保留简介演示，首页的探索按钮可直接体验。语音或文字明确指定它们的书名时，也会先检索正文；演示书上的「查找正文」提供同样入口。能否下载取决于书源是否实际提供该书，找不到时会显示结果，不会生成假的小说正文。

## 书源连接失败时

搜索会保留已成功书源的结果，并在失败项中显示书源名称及原因：DNS 解析失败、连接超时、连接被拒绝／中断、网络不可达、HTTPS 证书校验或握手失败；未能分类的错误仍显示连接失败。错误消息不包含底层原始地址或代理细节。某些书源失败时，不会将其解释成站点没有这本书。

点击失败项的「重试此书源」，只重新搜索该书源，保留同次查询的其他成功结果；重复失败会更新原因，恢复后会合并结果并移除对应错误。重试仍使用原查询书名，不会把尚未提交的输入框内容带入重试。程序不切换 VPN、不改系统 DNS／代理，也不跳过 HTTPS 证书校验。代理关闭后站点是否可连接，仍取决于实际网络；本功能用于给出准确提示并便于重试，不保证外站在所有网络下都可达。

## 存储与备份

Windows 默认位置为 `%APPDATA%\hexu-library\books`；其他系统默认 `~/.local/share/hexu-library/books`。界面的「正文书库 → 书库位置」显示实际路径。可用环境变量 `HEXU_BOOK_LIBRARY_DIR` 指定其他目录。

目录内包含：

| 文件 | 内容 |
| --- | --- |
| `library.sqlite` | 书目、完整章节、来源、书源规则与阅读进度 |
| `<书库ID>.txt` | UTF-8 全文副本，便于直接打开和备份 |

书库 ID 由来源与该来源的书籍标识生成，重复下载不会重复上架；书架槽位写入数据库，重启后位置稳定。网页将持久化槽位映射到物理位置，保留 HX 芯片编号与坐标。新增书目优先安排到文学书架，然后使用其他书架。移除样书后，通过清单中的数字兼容映射保持所有旧书库的位置不变；过去跳过的 12 个位置追加到末尾。

关闭程序后复制整个书库目录即可备份。程序更新与 Git 源码提交不包含用户书库；搬到另一台电脑时另行复制它。阅读已下载的正文不需要外网，但本机 HTTP 服务仍须运行。浏览器的语音识别是否能离线使用取决于所选识别通道。

## 书源与文件导入

内置 [天涯书库](https://tianyashuku.net/) 和 [书包网（简体）](https://cn.shubaoc.com/)。天涯书库使用站内 POST 表单搜索，书包网使用 `/search/<书名>/` 搜索；候选展示来源，确认下载后依次读取完整目录及正文，保存书名、作者和来源链接。书包网目录每页 100 章，适配器会自动翻到最后一页；正文只提取章节区域，排除推荐、导航及脚本。两个站点共用取消、去重、进度与完整入库流程，每个站点的请求至少间隔 350 毫秒。

历史维基文库下载的书籍、来源记录、书架编号和阅读进度继续保留；本地精确命中时不发起网络请求。内置源走代码中固定的 HTTPS 域名并保留证书校验，支持本机系统 DNS／网络代理；导入的自定义源仍逐次检查公网地址，不能通过 JSON 放宽限制。

「正文书库 → 书源管理与导入」提供 [源仓库](https://www.yckceo.com/yuedu/shuyuan/index.html) 入口。先下载 JSON 文件再导入；面板分别列出成功和拒绝的书源及原因。支持 CSS、XPath 1.0、JSONPath 和纯 JavaScript 规则，以及 Legado 3.x 的部分规则语法，**不等同于完整兼容阅读 App 的所有书源**。

支持 CSS 选择器及 `class.xxx@tag.a` 的基础链式写法；字段支持 `@text`、`ownText`、`href`、`@src`、`@title` 和 `@html`。XPath 使用 `@XPath:` 或 `//` 前缀；JSONPath 使用 `@Json:` 或 `$`，支持递归、通配和过滤。纯 JS 支持 `@js:`、`<js>...</js>`、`jsLib`、规则后的 JS 转换与 `##正则##替换`，可用变量为 `result`、`baseUrl`、`key`、`page`。每次执行限制 0.5 秒、32 MiB 内存，不提供本机文件、环境变量、进程或网络访问接口。

搜索 URL 支持 `{{key}}`、`{query}`、`{{page}}`（第一页）及 `{{JS表达式}}`；支持 `URL,{"method":"POST","body":"...","headers":{...}}` 请求选项。请求头仅允许 User-Agent、Accept、Accept-Language、Content-Type、Referer；正文为字符串，编码可为 UTF-8/GBK/GB18030。请求及跳转仍需符合该源同域与公网地址限制。

导入成功后默认启用，源文件标明 `enabled:false` 时保持停用；可在“书源管理与导入”的书源列表勾选开关，状态保存在本机。缺少搜索配置但具有书籍信息、目录与正文规则的源可以导入，标记“不提供搜索”，不会参加按书名搜索。在线书籍通过书名搜索后下载；本地书籍通过 TXT / EPUB 文件导入。`ruleBookInfo.tocUrl` 可指向独立目录，`nextTocUrl` 与 `nextContentUrl` 分别用于目录和正文分页，循环或中途失败不保存半本书。导入时只做离线规则验证；公网 DNS 检查在真正访问站点时进行。

以下为格式示例，需要改成实际站点的地址与选择器，不是可直接下载的书源：

```json
{
  "name": "My free-text source",
  "base_url": "https://example.com",
  "search_url": "/search?q={{key}}",
  "search": {
    "items": ".book-result",
    "title": "a.title@text",
    "url": "a.title@href",
    "author": ".author@text"
  },
  "toc": {
    "items": ".chapter-list a",
    "title": "@text",
    "url": "@href"
  },
  "content": {"body": "#chapter-content@text"},
  "license": "Publicly available free text; see source page"
}
```

暂不支持 Android／Java 宿主桥接（`java.*`、`Packages.*`）、设备注册、WebView 登录、验证码、跨域章节与图像/PDF 转文字，也不完整兼容 Legado 的所有选择器组合。依赖这些能力的源会明确显示原因并拒绝启用；导入时不会运行 JS，也不会绕过站点访问控制。本次检查的“番茄小说(APP)”源正文依赖 Java 加密和设备注册，尚不能使用；不能用纯 JS 支持代替这一运行环境。

自定义书源仅访问其同域公开 HTTP(S) 地址；本机、内网和保留地址被拒绝。代理返回保留地址的 DNS 环境也可能阻止站点访问。书源启用表示配置已保存、规则已验证，不保证外站可连接或每本书都提供可下载正文。

「导入 TXT / EPUB」支持 UTF-8、带 BOM 的 UTF-16 与 GB18030 TXT，以及无加密的 EPUB。EPUB 按 spine 顺序读取，并将 HTML 转为纯文本，脚本不会进入页面。导入的是本机实际文件内容，不会发送给大语言模型。

当前限制：单次导入文件 8 MiB，EPUB 解压后总量 32 MiB；在线单页响应 4 MiB，内置小说站与自定义书源一次最多 2000 章（历史维基文库适配器仍为 500 章）、目录最多 50 页、每章正文最多 20 页，整书最多 1000 万字符；最多两个同时下载任务。所有来源检索默认包括天涯书库、书包网及前五个已启用且支持搜索的自定义源，其他书源可通过下拉框单独选择。取消会在当前网络请求结束后生效；失败或取消的任务不会作为完整书籍入库，重试从头下载。

## 模块与接口

```text
ASR / 文字输入
       ↓
src/app/assistant.js → 本地书目匹配 → 3D 取书与封面开合
       ↓ 未入库                     ↓
src/reader/library.js       src/reader/novel.js
       ↓ 搜索 / 下载 / 导入          ↓ 章节 / 分页 / 进度
                  /library/*
                       ↓
              tools/book_library.py
                  ↙             ↘
       tools/book_sources.py    SQLite + UTF-8 TXT
          ↙          ↘
 天涯 / 书包网     CSS / XPath / JSONPath / JS 书源
```

`npm start` 的 Node 服务按需启动 `tools/library-service.py` 子进程并代理 `/library/*`；Python 本机程序与服务器则直接复用 `book_library`，两条运行路径使用相同的数据库与下载逻辑。正文显示使用 `textContent`，不会把远端 HTML 当作可执行页面。

| 接口 | 用途 |
| --- | --- |
| `GET /library/ready` | 探测书库服务与实际存储路径 |
| `GET /library/books` | 已入库目录 |
| `GET /library/books/<id>` | 全部章节与保存的阅读位置 |
| `GET /library/search?q=...&source=all` | 本地优先、在线候选与分来源错误 |
| `GET /library/sources` | 可用书源 |
| `POST /library/download` | 根据搜索候选建立异步任务 |
| `GET /library/jobs/<id>` | 下载状态和进度 |
| `POST /library/jobs/<id>` | 请求取消任务 |
| `POST /library/import` | 导入文件名与 Base64 文件内容 |
| `POST /library/sources` | 导入书源 JSON 对象或数组，返回能力与拒绝原因 |
| `POST /library/sources/<id>` | 设置 `{ "enabled": true/false }` |
| `POST /library/progress/<id>` | 保存 `chapter` 和 `offset` |

分页在当前窗口内测量真实文字高度，不使用固定字符数截断或简介占位。翻页的下一页起点等于上一页结束偏移，调整字号与窗口尺寸后重新排版；字符偏移让进度不依赖页码变化。

## 验证

```powershell
npm test
python -m unittest discover -s tests -p "test_*.py"
```

后端测试覆盖持久化、章节与进度恢复、重复入库、EPUB 顺序、脚本剔除、JS / XPath / JSONPath 混合下载、书源启停与停用状态持久化、目录分页、JS 超时及宿主隔离、取消和失败不入库、网络不可用时本地别名命中。界面改动还需在浏览器完成加载 → 找书 → 拖开封面 → 正文翻页 → 查看芯片 → 归还 → 待命，并检查字号、移动端排版与重新打开后的阅读进度。
