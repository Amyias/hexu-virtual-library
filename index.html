使用说明 ↗

先点击「启动语音感知」并允许麦克风。说「小和」，再说想找的书名；也可以一句说完。

这一次点击只需一次：授权之后，以后每次打开页面都会自动开始收听，直接说「小和」即可，无需再点。 （页面无法在未经你同意的情况下打开麦克风——浏览器的麦克风授权本身必须有用户手势，这不可绕过。）

支持：小和、小何、肖和、小荷、小禾、小鹤、xiao he。唤醒后等待 25 秒；未入库的书名会检索在线正文，多个候选时请在正文书库选择来源。

书名不必说得分毫不差：三字以上的书名差一个字（「时间减史」）或只说其中一段（「计算机」）都能命中， 识别器返回的多个候选也会一并参与匹配。二字书名（如《三体》）需要说准，或让候选里的正确写法命中。

说不出书名也没关系。服务器若配置了语义解析，规则理解不了的说法（「霍金写的那本」 「讲宇宙起源最著名的那本书」）会交给大语言模型判断要哪一本。规则能直接命中的不会绕这一趟， 所以常见说法仍然是即时的。

配置大模型对话：打开 本机设置 填写 API 密钥、接入地址和模型名称。点击右侧「和 · 对话」可以提问和连续追问，长回答在面板中完整显示，像素气泡显示摘要。DeepSeek 与其他 Chat Completions 兼容服务可随时切换，下一次提问生效；上下文仅保留当前页面最近 6 轮，点击「新对话」清空。未配置时仍能操作书架——找书照旧由本地规则即时完成，只是规则看不懂的说法会礼貌拒绝。 密钥保存在你自己的用户目录，不在程序目录里，也不会被任何页面显示出来。

正文阅读：说「小和，帮我找狂人日记」，或打开「正文书库」检索、下载或导入 TXT / EPUB。 正文下载完整后绑定到书架，翻开封面即可按页阅读，支持目录、字号与进度恢复。 阅读时也可以用嘴操作：翻开、合上、下一页、上一页、读正文、看看芯片、放回书架。

点击小和或说出唤醒词，会弹出像素气泡，文字逐字出现。右下角 ▥ 可独立关闭气泡与打字音效；音效在首次点击或键盘操作后可播放。语音播报默认关闭，右下角 ♪ 可开启播报，建议配合耳机以减少扬声器回声。

书架仅显示已导入或下载的真实书籍，未入库位置保持空置。找书默认由本地规则完成； 普通问答会把本次问题与最近对话发送至所配置的模型服务；自然语言找书会发送转写文本与真实馆藏目录—— 音频始终不出服务器。浏览器语音识别可能把音频发送至其识别服务，需要可用的网络；后台页面不保证持续识别。Web Speech API 说明

本地运行：在本文件目录终端执行 npm start，打开 http://localhost:8080 —— 正文书库需要 Python 3.10+，没有本机识别模型。含本机识别的完整功能请双击重新打包的「和序图书馆」 程序（见 DEPLOY.md 的「本机版打包」）：它自带识别模型与本机服务，直接打开自己的窗口， 里面同时提供站点、识别与语义解析。模型与渲染依赖均保存在本项目内。
