使用说明 ↗

先点击「启动语音感知」并允许麦克风。说「小和」，再说「帮我找三体」；也可以一句说完。

这一次点击只需一次：授权之后，以后每次打开页面都会自动开始收听，直接说「小和」即可，无需再点。 （页面无法在未经你同意的情况下打开麦克风——浏览器的麦克风授权本身必须有用户手势，这不可绕过。）

支持：小和、小何、肖和、小荷、小禾、小鹤、xiao he。唤醒后等待 25 秒；未匹配的书名会请你换一个关键词，不会随机定位。

书名不必说得分毫不差：三字以上的书名差一个字（「时间减史」）或只说其中一段（「计算机」）都能命中， 识别器返回的多个候选也会一并参与匹配。二字书名（如《三体》）需要说准，或让候选里的正确写法命中。

说不出书名也没关系。服务器若配置了语义解析，规则理解不了的说法（「霍金写的那本」 「讲宇宙起源最著名的那本书」）会交给大语言模型判断要哪一本。规则能直接命中的不会绕这一趟， 所以常见说法仍然是即时的。

配置语义解析：打开 本机设置 填写模型密钥。没有它也完全可用——找书照旧由本地规则即时完成，只是规则看不懂的说法会礼貌拒绝。 密钥保存在你自己的用户目录，不在程序目录里，也不会被任何页面显示出来。

阅读时也可以用嘴操作：翻开、合上、看看芯片、放回书架。

语音播报默认关闭，气泡回应始终开启；右下角 ♪ 可开启播报，建议配合耳机以减少扬声器回声。

这是含 11360 本编号馆藏的本地规则原型，其中 12 本有演示书目，其余为编号样书。找书默认完全由本地规则完成； 仅当服务器配置了语义解析且规则无法理解时，才把转写文本与馆藏目录发送至所配置的模型服务—— 音频始终不出服务器。浏览器语音识别可能把音频发送至其识别服务，需要可用的网络；后台页面不保证持续识别。Web Speech API 说明

本地运行：在本文件目录终端执行 npm start，打开 http://localhost:8080 —— 这是纯静态站点，没有本机识别模型。完整功能请双击打包好的「和序图书馆」 程序（见 DEPLOY.md 的「本机版打包」）：它自带识别模型与本机服务，直接打开自己的窗口， 里面同时提供站点、识别与语义解析。模型与渲染依赖均保存在本项目内。

每架沿 Z 轴延伸 8m，宽 1m、高 2m；给定坐标是架端引导点，A / B 书籍位于各架两侧。
