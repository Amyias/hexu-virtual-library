使用说明 ↗

先点击「启动语音感知」并允许麦克风。说「小和」，再说「帮我找三体」；也可以一句说完。

支持：小和、小何、肖和、小荷、xiao he。唤醒后等待 25 秒；未匹配的书名会请你换一个关键词，不会随机定位。

语音播报默认关闭，气泡回应始终开启；右下角 ♪ 可开启播报，建议配合耳机以减少扬声器回声。

这是含 12 本示例书的本地规则原型，不连接大模型。浏览器语音识别可能把音频发送至其识别服务，需要可用的网络；后台页面不保证持续识别。Web Speech API 说明

本地运行：在本文件目录终端执行 python -m http.server 8080，打开 http://localhost:8080。CDN 加载需要联网。

每架沿 Z 轴延伸 8m，宽 1m、高 2m；给定坐标是架端引导点，A / B 书籍位于各架两侧。
